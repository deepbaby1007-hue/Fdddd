이 문서는 앱이 의존하는 **선상24 실제 HTML 구조**를 기록해 둔 것입니다.
사이트가 개편되면 이 문서와 `Sunsang24Automation.kt` 의 선택자를 함께 고치면 됩니다.

확인한 페이지 (로그인 없이 볼 수 있는 공개 페이지):

- 출항일정: `https://araonfishing.sunsang24.com/ship/schedule_fleet/202612`
- 예약 진행: `https://araonfishing.sunsang24.com/mypage/reservation_ready/1586321`
- 로그인: `https://app.sunsang24.com/user/login?goto=…`

## 1. 출항일정 페이지 (`/ship/schedule_fleet/{YYYYMM}`)

### 날짜 블록

```html
<div id="d2026-12-06" class=" shipsinfo_daywarp sunday">
    <div class="date_info c_white">
        <span class="date c_white">6</span>
        <span class="unit c_white">일</span>
        <div class="date_right"><span class="swell">4물</span></div>
    </div>
    <!-- 배 목록 -->
</div>
```

- 날짜 id 규칙: `d` + `YYYY-MM-DD` (예: `d2026-12-06`)
- 같은 페이지에 한 달치 날짜 블록이 모두 들어 있습니다.

### 예약마감(만석)일 때

```html
<div class="detail">
  <span class="shipping_status" data-status_code="END">예약마감</span>
  <span class="number "> 21명</span>  예약 : <span class="number n_blue">21명</span>

<div class="detail">
  <button class="btn-info btn-sm btn_ship_reservation_awaiter" data-schedule_no="1586317">대기하기</button>

```

→ `button.btn_user_reservation` 이 없고 `span.shipping_status[data-status_code="END"]` 가 있으면 마감입니다.

### 예약 버튼 클릭 시 사이트 동작 (페이지 내 스크립트)

```js
$(document).on("click", ".btn_user_reservation", function () {
    if ($(this).data('ship_status_code') == "END_READY") {
        alert("현재 해당 선박은 유선 예약만 가능합니다.");
    } else {
        var schedule_no = $(this).data('schedule_no');
        var reservation_link;
        if (schedule_no > 0) {
            reservation_link = '/mypage/reservation_ready/' + schedule_no;
        } else {
            reservation_link = '/mypage/reservation_default_ready/' + $(this).data('sdate') + '/' + $(this).data('ship_no');
        }
        document.location.href = reservation_link;   // 모바일
    }
});
```

→ 그래서 앱은 버튼을 누르지 않고 **`/mypage/reservation_ready/{schedule_no}` 로 직접 이동**합니다.
(단, 화면에는 버튼도 그대로 보입니다)

### 로그인 여부 표시

- 로그아웃 상태 상단 메뉴: `<a href="https://app.sunsang24.com/user/login">로그인</a>`
- 앱은 `#navbar a[href*="user/login"]` 이 있으면 로그아웃으로 판단합니다.

## 2. 예약 진행 페이지 (`/mypage/reservation_ready/{schedule_no}`)

### 로그인이 풀린 상태

```html
<a href="https://app.sunsang24.com/user/login?goto=https%3A%2F%2Faraonfishing.sunsang24.com%2Fmypage%2Freservation_ready%2F1586321"
   class="btn_payment">로그인 후 예약하기</a>
```

→ `a.btn_payment` 의 문구에 "로그인"이 있으면 로그인 필요.

### 인원 선택

```html
<dt class="num_modify">
  <span class="title">인원선택</span>
  <div class="user_count" data-price_option='{"no":0,"price":100000,"required_person":1}'>
    <a href="javascript:;" class="minus"><img src="…/btn_minus.gif" alt=""></a>
    <span class="people_count">0</span>
    <a href="javascript:;" class="plus"><img src="…/btn_plus.gif" alt=""></a>
  </div>
</dt>

<input type="hidden" name="person_count" value="0"/>
```

- 페이지가 열리면 사이트가 자동으로 `a.plus` 를 한 번 눌러 인원을 1로 맞춥니다
  (`if (data.schedule.remain_embarkation_num >= 1) { $("dt.num_modify").first().find("a.plus").trigger("click"); }`).
- `input[name=person_count]` 는 숨은 값이며, `a.plus`/`a.minus` 클릭 시 갱신됩니다.

### 금액

### 예약 버튼과 검증 로직 (`#btn_payment`)

사이트 스크립트가 `#btn_payment` 클릭 시 아래를 검사합니다.

```js
if ($("input[name='person_count']").val() < 1)        alert("예약인원을 선택 해 주시기 바랍니다.");
if ($("input[name='name']").val() == '')              alert("예약자명을 입력 해 주시기 바랍니다.");
if (phone1/2/3 중 빈 값)                              alert("휴대전화를 입력 해 주시기 바랍니다.");
if (!is_phone_auth)                                   alert("휴대전화 인증을 해주시기 바랍니다.");
if ($("input[name='agree_rule[]']:checked").length < 3) alert("필수 약관에 동의 바랍니다.");
if (is_imminent_departure && !imminent_departure_agreed) { show_imminent_departure_modal(); return false; }

reservation_confirm_msg = "[아라온피싱호] 2026.12.6(일)\n예약인원: 2명\n결제금액: 200,000원\n결제방식: 무통장 입금\n\n예약을 하시겠습니까?";
reservation_confirm();   // → confirm(reservation_confirm_msg)
```

확인을 누르면:

```js
$.ajax({
  url: '/mypage/reservation_end', method: 'POST', data: $("#form-reservation").serialize(),
  success: function (data) {
    if (typeof data.reservation_no != "undefined") {
      document.location.href = '/mypage/reservation_detail/' + data.reservation_no + '?is_menu_noview=1';
    } else { alert(data.message); }
  }
});
```

→ **성공 판정은 `/mypage/reservation_detail/{no}` 로 이동했는지**로 합니다.
→ 실패는 `alert(data.message)` 로 뜹니다.

### 출항 임박 안내 모달 (당일·전날)

```html
<div class="modal fade" id="modal_imminent_departure" …>
  <h4>[출항 임박 예약 안내]</h4>
  <button id="btn_imminent_departure_agree" class="btn btn-primary btn-imminent-agree">동의함</button>
</div>
```

동의 후 모달이 닫히면 사이트가 `#btn_payment` 를 다시 클릭합니다.

### 입력 필드 이름 정리

| 필드 | 선택자 |
|---|---|
| 예약자명 | `input[name='name']` |
| 휴대전화 | `input[name='phone1']`, `input[name='phone2']`, `input[name='phone3']` |
| 인원(숨김) | `input[name='person_count']` |
| 인원 UI | `div.user_count > a.plus / a.minus / span.people_count` |
| 약관 | `input[name='agree_rule[]']` (필수 3개 이상) |
| 예약 버튼 | `#btn_payment` |
| 결제 방식 | `input[name='reservation_method']` = `bank` (무통장) |

## 3. 앱이 쓰는 선택자 요약

| 목적 | 선택자 |
|---|---|
| 날짜 블록 | `#d{YYYY-MM-DD}`, `.ship_info_warp[data-sdate="{YYYY-MM-DD}"]` |
| 배 이름 | `.title .modal-ship-detail` |
| 남은 자리 | `.seat .blink_me` |
| 예약 가능 버튼 | `button.btn_user_reservation` |
| 마감 표시 | `.shipping_status[data-status_code="END"]` |
| 로그아웃 상태 | `#navbar a[href*="user/login"]` |
| 로그인 필요(예약페이지) | `a.btn_payment` (문구에 "로그인") |
| 인원 | `div.user_count` |
| 약관 | `input[name='agree_rule[]']`, `input[name='agree_all']`, `input.user_check` |
| 예약 실행 | `#btn_payment` |
| 임박 안내 | `#modal_imminent_departure`, `#btn_imminent_departure_agree` |
| 완료 확인 | URL `/mypage/reservation_detail/{no}` |

## 4. 개편되었을 때 확인하는 방법

1. 폰을 USB로 연결하고 PC 크롬에서 `chrome://inspect` 를 엽니다.
   (앱의 디버그 빌드는 웹뷰 디버깅이 켜져 있습니다)
2. 앱에서 해당 페이지를 열면 목록에 나타납니다 → **inspect** 를 눌러 개발자 도구로 HTML 확인.
3. 바뀐 클래스/이름을 위 표와 `Sunsang24Automation.kt` 에 반영합니다.

또는 PC 브라우저에서 페이지 소스 보기(`Ctrl+U`)로 같은 구조를 확인할 수 있습니다.
