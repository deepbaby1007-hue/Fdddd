# 선상24 자동 예약 앱 (Android / Kotlin)

선상24(예: `araonfishing.sunsang24.com`)에서 **자리가 나는지 지켜보다가, 자리가 있으면 예약 페이지까지 채워 주는** 안드로이드 앱입니다.
원하시면 **최종 확인 창까지 자동 승인해서 예약 접수**까지 진행할 수도 있고, 안전하게 **예약 버튼 직전에서 멈추고 알림만** 받을 수도 있습니다.

> 이 폴더는 **소스 코드 프로젝트**입니다. 그대로는 폰에 설치되지 않고, Android Studio에서 한 번 빌드해서 APK로 만들어 설치합니다.
> 아래 순서대로만 따라 하시면 됩니다. (30분 정도 걸립니다)

---

## 1. 무엇을 해 주는 앱인가요?

| 기능 | 설명 |
|---|---|
| 카카오 로그인 유지 | 앱 안에서 한 번 로그인하면 쿠키가 저장되어, 앱을 껐다 켜도 로그인이 유지됩니다. |
| 지정 시각 오픈런 | "10:00:00에 예약이 열린다"처럼 시각을 정해 두면, 그 시각까지 기다렸다가 바로 확인을 시작합니다. |
| 빈자리 주기 감시 | 취소 자리가 나는지 5초 이상 간격으로 계속 확인합니다. |
| 자동 입력 | 인원수(+/-), 예약자명, 휴대전화, 필수 약관 동의를 자동으로 채웁니다. |
| 자동 최종 확인 | 켜면 예약 확인 창을 자동 승인해 실제로 예약을 접수합니다. (무통장 입금 예약) |
| 알림·진동 | 자리 발견 / 예약 시도 / 예약 완료 때 알림과 진동으로 알려 줍니다. |
| 설정 저장 | 선사·배·날짜·인원·예약자 정보를 저장해 두어 매번 입력하지 않아도 됩니다. |

**중요**: 결제는 하지 않습니다. 선상24의 무통장 입금 예약은 "예약 접수"까지만 앱이 하고,
입금은 예약 후 3일 이내에 직접 하셔야 합니다. (미입금 시 자동 취소됩니다)

## 2. 준비물

1. **PC (Windows / macOS)** — Android Studio를 설치할 수 있는 컴퓨터
2. **Android Studio** — <https://developer.android.com/studio> 에서 내려받아 설치
   - 설치할 때 JDK(자바)가 함께 설치되므로 따로 준비할 것은 없습니다.
   - 첫 실행 때 "Standard" 설치를 선택하면 SDK까지 자동으로 받습니다.
3. **안드로이드 폰** — USB 케이블 또는 파일 전송 수단

---

## 3. 프로젝트 열기 (처음 한 번)

1. `sunsang24-auto-booking-android.zip` 압축을 풉니다. (예: `C:\dev\` 또는 `~/dev/`)
2. Android Studio를 실행합니다.
3. 시작 화면에서 **Open** (또는 `File > Open`) 을 누르고, 압축을 푼 **`sunsang24-auto-booking-android` 폴더**를 선택합니다.
   - ⚠️ 폴더 **안의** 파일이 아니라, `settings.gradle.kts` 가 들어 있는 **폴더 자체**를 선택하세요.
4. 오른쪽 아래에 "Gradle Sync" 진행 표시가 나옵니다. 처음에는 Gradle과 라이브러리를 내려받느라 **5~15분** 걸릴 수 있습니다.
   - 인터넷이 필요합니다.
   - "Sync Project with Gradle Files" 안내가 뜨면 눌러 주세요.
5. 아래쪽에 `BUILD SUCCESSFUL` 또는 오류 없이 초록 체크가 뜨면 준비 끝입니다.

> 처음 열 때 "Android Gradle Plugin 업데이트 권장" 같은 안내가 뜰 수 있습니다.
> **Don't remind me again / 그대로 두기** 를 눌러도 정상 동작합니다.

## 4. APK 만들기 (설치 파일 뽑기)

1. 위쪽 메뉴에서 **Build > Build Bundle(s) / APK(s) > Build APK(s)** 를 누릅니다.
2. 1~3분 기다리면 오른쪽 아래에 "APK(s) generated successfully" 알림이 뜹니다.
   - **locate** 를 누르면 파일 위치가 열립니다.
3. 만들어진 파일:

   ```
   sunsang24-auto-booking-android/app/build/outputs/apk/debug/app-debug.apk
   ```

이 `app-debug.apk` 하나만 폰에 옮기면 됩니다.

## 5. 폰에 설치하기

### 방법 A. USB로 연결해서 설치 (권장)

1. 폰에서 **설정 > 휴대전화 정보 > 소프트웨어 정보 > 빌드번호**를 7번 연속 탭 → 개발자 옵션이 켜집니다.
2. **설정 > 개발자 옵션 > USB 디버깅** 을 켭니다.
3. 폰을 USB로 PC에 연결하고, 폰 화면에 뜨는 "USB 디버깅을 허용하시겠습니까?"에서 **허용**.
4. Android Studio 위쪽 기기 목록에서 내 폰을 선택하고 **Run ▶** 을 누르면 바로 설치·실행됩니다.

### 방법 B. APK 파일만 폰으로 옮겨서 설치

1. `app-debug.apk` 를 카카오톡 "나에게 보내기", 구글 드라이브, USB 등으로 폰에 옮깁니다.
2. 폰에서 파일을 열면 "출처를 알 수 없는 앱 설치" 안내가 뜹니다 → **설정으로 이동 → 이 앱 허용**(파일 관리자/크롬 등) → 다시 설치.
3. 설치 후 홈 화면의 **선상24 자동예약** 아이콘을 누르면 실행됩니다.

> 구글 플레이 스토어에는 올리지 않습니다. 본인 폰에만 설치하는 개인용 앱입니다.

## 6. 사용법 (3단계)

### ① 먼저 카카오 로그인 (처음 한 번만)

1. 앱에서 **선사 서브도메인**을 입력합니다. (예: `araonfishing`)
2. **"카카오 로그인 먼저 하기"** 버튼을 누릅니다.
3. 열린 화면에서 **카카오 아이디로 로그인** → 카카오 계정으로 로그인합니다.
   - 카카오톡 앱으로 넘어가면 로그인 후 다시 앱으로 돌아옵니다.
4. 선상24 출항일정 화면이 보이고 상단에 **로그아웃/마이페이지**가 보이면 성공입니다. **닫기**를 누릅니다.
5. 로그인 상태는 저장됩니다. (카카오 쪽에서 세션이 만료되면 다시 로그인해야 합니다)

### ② 배·날짜·인원 설정

| 항목 | 설명 |
|---|---|
| 선사 서브도메인 | `araonfishing` 처럼 주소 앞부분만. (`https://` 는 넣지 않아도 됩니다) |
| 배 이름 | 예: `아라온피싱호`. **비워 두면** 그 날 예약 가능한 첫 번째 배를 노립니다. |
| 출조 날짜 | 칸을 탭하면 달력이 열립니다. (`2026-12-06` 형식) |
| 인원 수 | 예: `2` |
| 예약자명 | 예: `홍길동` |
| 휴대전화 | 숫자만. 예: `01012345678` |

### ③ 자동 예약 시작

- **동작 방식**을 고릅니다.
  - **① 지정 시각 오픈런**: `오픈 시각`(예: `10:00:00`)을 입력 → 그 시각까지 기다렸다가 확인 시작
  - **② 빈자리 주기 감시**: `감시 간격`(초)을 입력 → 계속 확인 (최소 5초)
- **자동 최종 확인까지 진행** 스위치
  - **끄면(기본)**: 예약 버튼 직전에서 멈추고 알림 → 화면에서 **예약하기**만 누르면 됩니다. (가장 안전)
  - **켜면**: 확인 창을 자동 승인해서 예약 접수까지 진행합니다.
- **자동 예약 시작** 버튼을 누르면 실행 화면이 열리고, 실제로 사이트를 오가는 과정이 화면에 보입니다.

실행 화면 아래쪽 **로그**에 `감시 중 · 3회`, `자리 발견`, `예약 시도 중`, `완료` 처럼 진행 상황이 표시됩니다.
멈추려면 오른쪽 위 **중지**를 누릅니다.

## 7. 동작 원리 (궁금하실 때)

```
[출항일정 페이지]  https://{선사}.sunsang24.com/ship/schedule_fleet/{YYYYMM}
        │  자바스크립트로 그 날짜·그 배의 "남은자리"와 "바로예약" 버튼을 확인
        ▼
[자리 있음]        https://{선사}.sunsang24.com/mypage/reservation_ready/{schedule_no}
        │  인원 +/- 클릭, 예약자명·휴대전화 입력, 필수 약관 체크
        ▼
[예약하기 클릭]    사이트가 띄우는 confirm() 창을 자동 승인 (스위치가 켜진 경우)
        ▼
[예약 접수 완료]  https://{선사}.sunsang24.com/mypage/reservation_detail/{예약번호}
```

- 로그인 쿠키는 앱 내부 WebView의 `CookieManager`에 저장되어 유지됩니다.
- 사이트가 jQuery로 값을 읽기 때문에, 앱은 값을 넣은 뒤 `input`/`change` 이벤트를 직접 발생시킵니다.
- 페이지 구조(선택자)가 바뀌면 `docs/선상24-페이지-구조.md` 와 `Sunsang24Automation.kt` 를 참고해 고치면 됩니다.

## 8. 꼭 알아 두실 점 (정직한 안내)

1. **봇 차단/과도한 요청**
   선상24를 비롯한 예약 사이트는 짧은 간격의 반복 요청을 차단할 수 있습니다.
   그래서 감시 간격의 **최소값을 5초**로 막아 두었습니다. 5초보다 짧게 바꾸려면 코드를 고쳐야 하고, 그렇게 하는 것은 권하지 않습니다.
   차단되면 계정이 일시 정지되거나 예약이 막힐 수 있습니다.

2. **카카오 로그인 세션 만료**
   카카오/선상24 쪽에서 세션이 끊기면 예약 페이지에서 **"로그인 후 예약하기"** 만 보입니다.
   이때 앱은 "로그인이 풀렸습니다"라고 알려 주고 멈춥니다. 다시 **카카오 로그인 먼저 하기**를 눌러 주세요.

3. **화면을 켜 두세요**
   자동 예약 중에는 폰 화면이 꺼지지 않게(앱이 자동으로 `KEEP_SCREEN_ON`을 켭니다) 되어 있지만,
   다른 앱을 오래 쓰거나 폰이 앱을 정리하면 감시가 멈출 수 있습니다.
   중요한 날에는 **충전기를 꽂고 앱을 띄워 두는 것**을 권합니다.

4. **결제·입금은 직접**
   앱은 **무통장 입금 예약 접수까지만** 합니다. 입금은 예약 후 3일 이내(사이트 기준)에 직접 해 주세요.
   입금자명은 배 안내문 규정(예: `1206 홍길동`)을 확인하세요.

5. **출항 임박(당일·전날) 예약**
   사이트는 당일/전날 예약 시 "출항 임박 안내" 창을 띄웁니다. 앱은 이 창의 **동의함**까지 자동으로 누릅니다.
   다만 이 경우 선사에 전화로 확인하는 것이 안전합니다.

6. **사이트 개편**
   선상24가 홈페이지를 바꾸면 자동 입력이 동작하지 않을 수 있습니다.
   이때는 로그에 "예약 페이지 구조를 알아보지 못했습니다"가 뜹니다. `docs/선상24-페이지-구조.md` 의 선택자를 새 화면에 맞게 고쳐 주세요.

7. **이용약관·책임**
   이 앱은 본인 계정으로 본인 예약을 돕는 개인용 도구입니다.
   사이트의 이용약관, 자동화 금지 조항, 봇 정책을 직접 확인하시고 사용 여부를 판단해 주세요.
   사용으로 생기는 계정 제재·예약 문제의 책임은 사용자에게 있습니다.

## 9. 자주 겪는 문제

| 증상 | 해결 |
|---|---|
| `Gradle sync failed` | 인터넷 연결 확인 → `File > Invalidate Caches / Restart` → 다시 Sync. 회사·학교 네트워크에서 막히는 경우도 있습니다. |
| `SDK location not found` | Android Studio가 SDK를 못 찾은 경우. `Tools > SDK Manager`에서 Android 14 (API 34) SDK 설치 후 다시 Sync. |
| 빌드는 되는데 폰에 설치 안 됨 | 폰의 "출처를 알 수 없는 앱" 허용, USB 디버깅 허용 확인 |
| 앱은 켜지는데 화면이 하얗다 | 인터넷 권한/네트워크 확인. 실행 로그에 `네트워크 오류`가 있는지 보세요. |
| "로그인이 풀렸습니다" | 카카오 로그인을 다시 진행 (세션 만료) |
| "요청한 N명을 선택하지 못했습니다" | 남은 자리가 부족한 상태입니다. 인원을 줄이거나 다시 감시하세요. |
| "휴대전화 인증을 해주시기 바랍니다" | 선상24가 휴대전화 인증을 요구하는 계정입니다. 사이트에서 한 번 인증한 뒤 다시 시도하세요. |
| 예약했는데 알림이 안 옴 | 설정 > 앱 > 선상24 자동예약 > 알림 허용 확인 |

## 11. 코드를 고치고 싶다면

- **감시 간격/기본값**: `BookingSettings.kt` 의 `MIN_INTERVAL_SEC`
- **예약 페이지 자동 입력 규칙**: `Sunsang24Automation.kt` 의 `prepareReady()`
- **자리 확인 규칙**: `Sunsang24Automation.kt` 의 `scanSchedule()`
- **진행 순서/재시도 횟수**: `BookingEngine.kt` 의 `PAGE_TIMEOUT_MS`, `readyRetries` 제한
- **화면 문구/레이아웃**: `res/layout/*.xml`

앱 식별자는 `com.sunsang24.autobooking` 입니다. 바꾸려면 `app/build.gradle.kts` 의 `namespace`·`applicationId` 와
Kotlin 패키지 경로를 함께 바꿔야 합니다.
